# H3 双采接续与 PH3 图像编辑

从「管理 → 新建任务 → 简易添加」选择工作流。两条工作流在 ComfyUI 中使用同一套 H3 Toolbox 节点和素材库。

| 工作流 | 简称 | 简易添加 |
| --- | --- | --- |
| H3 双采接续 | `h3-dual` | 参考素材、提示词、生成设置、片段选择、视频裁切和成片拼接 |
| PH3 图像编辑与生成 | `ph3` | 图片参考项目库、卡片启停和排序、输入提示词 |

## 与 ComfyUI WebUI 共享

两端连接同一个 ComfyUI 实例时，会使用同一套 Toolbox 素材项目和片段库。两个工作流的默认成品路径如下。

| 内容 | 相对于 ComfyUI `output/` 的路径 |
| --- | --- |
| H3 一采视频 | `最终版万物皆可接续/1采/` |
| H3 二采视频 | `最终版万物皆可接续/2采/` |
| H3 接续片段 | `amiaomiao-h3-clips/<项目>/` |
| H3 拼接成片 | `h3_long/` |
| PH3 图片 | `鸣潮画风测试/` |

AstrBot 会兼容已安装的 v4.0.0 默认输出值，并保留自行设置的输出前缀。ComfyUI WebUI 可直接打开随包 AstrBot 画布。PH3 在评价图集中保存可独立整理的副本，原图继续留在共享输出目录。

从安装 ZIP 中，将 `comfyui/ComfyUI-AstrBot-H3-Shared` 整个文件夹复制到 ComfyUI 的 `custom_nodes/`，重启 ComfyUI 并刷新页面。在两端的提示词框旁都可使用「共享提示词库」按名称保存、载入、刷新和删除。H3 双采和 PH3 各有自己的库，保存到同一个 ComfyUI 用户目录下的 `astrbot_h3_shared/`。默认单用户实例两端均使用 `default` 用户。

## H3 双采接续

1. 在「H3 参考素材」添加图片或音频，或从视频项目中选择参考片段。提示词面板显示启用素材及对应编号。
2. 在「生成设置」填写时长、横竖画幅、一采像素量和二采放大倍数。时长按 H3 的 `17n+5` 帧对齐。跟随参考视频需要启用 Video 1。
3. 在「接续控制台」选择项目。第一次用「全新段落」，之后可跟随最新片段或固定某个前段。选择「只一采」保存草稿，再从草稿卡片发起二采。二采恢复草稿保存的输入。
4. 「视频裁切处理」和「成片拼接」是独立任务。先打开对应面板，配置源视频或镜头顺序，再点击「运行裁切」或「运行拼接」。拼接可以从双采库优先选择二采，也可使用单采库。

「选择视频」会打开当前设备的选文件窗口并将文件上传到 ComfyUI input。也可在下拉框选择 input 视频。手填路径须位于配置的 ComfyUI input 或 output。裁切、拼接和有声视频读取依赖 ComfyUI 进程能使用 `ffmpeg` 和 `ffprobe`。

## PH3 图像编辑与生成

「H3 图片参考」提供 9 个启用槽位。停用的卡片留在项目中，启用卡片的输出顺序决定提示词里的 `<Picture N>`。填写编辑要求时可直接引用编号。清空启用槽位后输入描述即可文生图。输出尺寸、模型和可选的提示词改写在工作流参数页设置。

## ComfyUI 依赖与画布

需要已安装的 ComfyUI-ximiao-H3-Toolbox、原画布使用的 H3／PH3 模型与其他自定义节点。AstrBot 附带的画布位于 `templates/`，相应运行图位于 `workflows/`。新项目会从干净的参考槽和提示词开始，可在面板中重新选用现有 Toolbox 项目。

维护用导出工具为 `scripts/export_h3_toolbox.py`。它从指定目录读取两份原始画布及当前 ComfyUI 的节点定义。需要单独供 ComfyUI 使用的 API 图时可加 `--api-output`。
