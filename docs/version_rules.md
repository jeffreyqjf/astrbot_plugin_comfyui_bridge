# 版本规则

插件版本使用 `vMajor.Minor.Patch`。以 [metadata.yaml](../metadata.yaml) 为版本来源，正式变更时同步核对 README 与受影响的用户文档。

| 级别 | 适用范围 | 例子 |
| --- | --- | --- |
| Major | 重大不兼容变化，后两位归零 | 移除原有公开指令，或改变旧数据读取约定 |
| Minor | 新增兼容功能，Patch 归零 | 新增工作流或工作台功能 |
| Patch | Bug 修复和小型优化 | 修复图片分页、节点默认值或错误反馈 |

正式版本更新时确认版本类型、兼容性、迁移影响、相关工作流三个版本、随包文件和验证结果。在交付中输出一行与实际变更匹配的 Git Commit Message。例如 `chore(release): bump version to v2.25.0`。是否执行提交、推送或发布由用户授权决定。内部维护文档和 Agent 初始化无需自动提升业务版本。
