# 新建任务输入核对

v4.0.0 的 `h3-dual` 和 `ph3` 使用 Toolbox 原版控件。H3 双采可配置参考图、视频、音频、提示词、时长、画幅和接续。裁切与拼接各自提交独立任务。PH3 使用图片参考卡片和多行提示词。

v3 在下列基本输入之上新增 `features` 功能目录。Advanced Gemma V40 提供 OpenPose、Any ControlNet、RGB 区域提示词；Anima T2I 提供 LLLite。只勾选常用功能才显示配置，其他已存在的专用任务输入和工作流参数保留。详情见 [使用教程](../user%20docs/REGIONAL_PROMPT.md)。

v2.39.0 按已加载工作流的实际映射生成任务能力。以下是随包默认配置；用户保存分支后，以当前图重新计算。批次数量适用于所有生成任务；LoRA 列表仅在实际工作流配置了可用目录时显示；ControlNet 按支持的分支单独呈现。

| 工作流 | 提示词与预设 | 单张参考图／素材 | 其他专用输入 |
| --- | --- | --- | --- |
| Anima T2I | 正向、负向、普通预设 | 取决于已保存的图生图分支与来源 | LoRA、LLLite |
| Anima I2I AIO | 正向、负向、普通预设 | 可选参考图，有图时构建图生图分支，无图时文生图 | 配置为遮罩路径时显示遮罩入口 |
| Advanced Gemma V40 | 正向、负向、普通预设 | 仅在当前主图包含参考图字段时显示 | LoRA、OpenPose、Any ControlNet |
| Detailer V40 | 正向、负向、普通预设 | 当前分支必需参考图 | 遮罩按连线显示 |
| WAI-Illustrious T2I | 正向、负向、普通预设 | 默认无单图入口 | 已配置的 LoRA |
| SDXL Turbo | 正向、负向、普通预设 | 无 | 通用映射 |
| WAN22 T2V | 正向、负向、普通预设 | 无 | 简易添加支持按秒指定时长 |
| WAN22 I2V | 正向、负向、普通预设 | 必需参考图 | 简易添加支持按秒指定时长 |
| WAN22 SVI I2V | 正向、负向、普通预设 | 必需参考图 | 简易添加支持按秒指定总时长，沿用工作流的分段配置 |
| WAN22 Lightning I2V | 正向、负向、普通预设 | 必需参考图 | 同上 |
| MiniMax H3 Seed Hunter 简化版 | 正向、普通预设，无负向输入 | 当前模式连接到 #5 时支持可选参考图 | 简易添加支持按秒指定时长 |
| MiniMax H3 Seed Final 简化版 | 同上 | 同上 | 不显示完整版编辑器 |
| MiniMax H3 Seed Hunter v3 完整版 | H3 Prompt IDE 与独立模板，无负向及普通预设 | #416 在执行路径时使用媒体加载器，隐藏重复的单张参考图入口 | 提示词／模板 JSON 导入导出、TXT 导入、当前模式的时长输入 |
| Anima Reverse | 无生成提示词输入 | 不加入生成任务表单 | 使用图片反推入口 |

遮罩能力检查 LoadImage 的第 1 个输出是否连接到实际执行路径。AIO 按带参考图的候选分支检查，避免文生图默认图导致误判。参考图已选但切到不支持的工作流时，旧图不提交。H3 完整版媒体分支不在当前执行路径时，媒体控件及引用列表均停用。

验证包括：隔离 AstrBot 中全部 14 条工作流的能力映射、AIO 和三条 WAN 图生视频参考图进入实际任务图、H3 无效输入拒绝、预设负向兼容；浏览器检查工作流切换、隐藏字段不入参、H3 导入导出和桌面／手机布局。GPU 生成与 QQ 投递不在本次验证范围。
